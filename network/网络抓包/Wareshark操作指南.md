# Wireshark入门指南
## 一、简单介绍
Wireshark 是**全网层抓包神器**，比 Proxyman 更底层：
- Proxyman 只能抓 **HTTP/HTTPS 应用层**
- Wireshark 能抓 **TCP/UDP/IP/ARP/DNS/全网所有流量**
适合：排查网络卡顿、端口通不通、DNS 解析、局域网攻击分析、设备通信、游戏底层协议。

## 二、安装与基础准备
1. 官网下载：直接搜 Wireshark 官网，默认下一步安装
2. 必装组件：**WinPcap/Npcap** 一定要勾选，不然抓不到网卡
3. 运行权限：**Windows 必须右键以管理员身份运行**

### 核心界面一眼看懂
- 上方：菜单栏、开始/停止抓包、过滤栏
- 中间：数据包列表（时间、源IP、目的IP、协议、信息）
- 下方：数据包详情层、原始二进制数据

## 三、第一步：选择网卡开始抓包
1. 打开 Wireshark，首页会列出所有网卡：
   - 以太网（网线）
   - Wi-Fi 无线网卡
   - 虚拟机网卡、Loopback 本地回环
2. **双击你正在上网的网卡**，直接开始抓包
3. 想停止：点左上角红色方块按钮

> 小技巧：只选当前在用网卡，别全选，流量太乱

## 四、最常用：过滤表达式（必学，减少垃圾流量）
在顶部过滤栏输入，回车生效

### 1. 按协议过滤
```
tcp
udp
http
dns
arp
icmp  # ping 包
```

### 2. 按 IP 过滤
```
ip.src == 192.168.1.105   # 源IP
ip.dst == 220.181.xxx.xxx # 目的IP
ip.addr == 192.168.1.105  # 只要包含这个IP都抓
```

### 3. 按端口过滤
```
tcp.port == 80
tcp.port == 443
udp.port == 53   # DNS
```

### 4. 组合过滤
```
tcp && ip.addr == 192.168.1.105
dns && udp.port == 53
```

## 五、各大实操抓包场景
### 场景1：抓网页 HTTP/HTTPS 流量
1. 选中网卡开始抓包
2. 过滤栏输入：`http`
3. 打开浏览器随便访问网页，就能看到：
   - GET/POST 请求
   - 请求地址、状态码
4. HTTPS 默认是加密的，**Wireshark 不能直接解密**（不像 Proxyman 装证书就能看），只能看到 TCP 握手，看不到明文内容。

### 场景2：抓 DNS 解析（排查网站打不开）
1. 过滤：`dns`
2. 打开浏览器访问域名
3. 看流程：
   - DNS Query 发起解析
   - DNS Response 返回 IP
   没响应就是 DNS 故障。

### 场景3：抓 Ping 包（ICMP）
1. 过滤：`icmp`
2. cmd 输入：`ping 百度.com`
3. 能看到：请求、回应、超时丢包，排查网络延迟/丢包神器。

### 场景4：抓局域网 ARP 协议（查同网段设备IP）
1. 过滤：`arp`
2. 自动扫描局域网，可看到：
   - 谁在发 ARP 请求
   - IP 对应 MAC 地址
   适合找未知设备、查局域网谁在线。

### 场景5：抓手机/平板同一局域网流量
1. 电脑和手机连**同一个 Wi-Fi**
2. Wireshark 选 Wi-Fi 网卡抓包
3. 过滤：`ip.addr == 手机IP`
就能看到手机所有底层网络收发数据。

### 场景6：抓游戏、软件 UDP/TCP 底层通信
很多游戏、直播、即时通讯用 UDP：
1. 过滤：`udp` 或 `tcp`
2. 打开游戏/软件操作
3. 看它连哪些服务器、用什么端口、发包频率。

## 六、基础操作：怎么看单个数据包
1. 点任意一条数据包
2. 下层分三层：
   - **Frame**：整个数据包概况
   - **Ethernet**：MAC 地址
   - **IPv4**：源目 IP、TTL
   - **TCP/UDP**：端口、握手信息
   - **HTTP/DNS**：应用层明文数据

3. 右键数据包：
   - 追踪流 → TCP流 / UDP流
   可以把一次完整会话全部整理出来，一目了然。

## 七、保存/打开抓包文件
1. 停止抓包 → 文件 → 保存，后缀 `.pcapng`
2. 别人发的抓包文件，直接双击用 Wireshark 打开即可分析。

## 八、常见问题快速排错
1. 选了网卡没流量
   - 没开管理员权限
   - Npcap 没装好
   - 选错网卡

2. 全是乱码、看不懂
   - 加过滤表达式，不要裸抓
   - HTTPS 本身加密，Wireshark 无法直接看明文

3. 手机抓不到
   - 电脑手机必须同 Wi-Fi
   - 电脑连网线、手机连Wi-Fi 不在一个网段，抓不到

## 九、Wireshark 和 Proxyman 简单区别
- **Proxyman**：只抓应用层 HTTP/HTTPS，适合接口调试、APP 抓包，傻瓜式带证书解密
- **Wireshark**：抓底层全网流量，TCP/UDP/ARP/ICMP 都能抓，适合网络排查、底层协议分析
